### 🧠 about

i’m a **software engineer first**, ai engineer by depth.

i build **end-to-end systems** — from backend apis and full-stack apps  
to **genai pipelines, agentic systems, and secure production deployments**.

started coding in **12th grade**, followed a deliberate path:

```
python → ds → ml → nlp → genai → agentic ai
```

i care less about demos and more about:
- how systems fail  
- how they scale  
- how trust is measured  
- how security holds under pressure  

> building a model is easy  
> building a **secure, explainable system** is not
